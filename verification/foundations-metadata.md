# Paper I mathematical scope

The quotient criterion uses the first isomorphism theorem and the algebraic GNS construction. The finite parity system is a standard finite Weyl algebra. The paper uses these facts to distinguish three tests for a proposed gravitational comparison: descent of probe relations, injectivity on an embedding and intertwining of boundary actions. It gives an explicit largest compatible family of locally invisible ideals and a preparation description of that family. No priority claim is made for these algebraic constructions.

The two-bit example includes a proper arrow that commutes with the matrix comparison and a first-order corner-bracket test is given on a putative linear canonical sector. A physical application still needs an independent calibration of gravitational word moments, a dressing for a small patch inside a larger diamond and the appropriate common operator domains.

The bibliography includes primary treatments of locally covariant algebras, curved-spacetime cyclicity, classical surface charges, the covariant phase space with boundaries, null canonical data, symmetries of causal diamonds, and the three manuscripts motivating the program. Paper II can use the state and boundary distinction when considering reduction. Paper III can test whether maps that preserve local relations also preserve the data at a shared cut.
